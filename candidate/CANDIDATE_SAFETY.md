# Повторно восстановленный синтетический кандидат — НЕ РЕЛИЗ

Это новая реконструкция из публичного GitHub `viformatik/Fitness_app` commit `e460050454e6a60a3c21b641006b7258d2c80309`, а не побайтовое восстановление утраченного последнего кандидата. **Не развёртывать, не применять SQL, не подключать реальные аккаунты, не открывать существующий дневник.** Исходники — не копия пользовательских записей.

- Web-оболочка предназначена только для `127.0.0.1`; тесты запускать в одноразовом профиле и изолированном loopback namespace. Guard не защищает нативные сборки. Только это имя хоста не запрещает исходящие запросы: изоляция сети обязательна.
- Хранилище переименовано в `fitness_synthetic_candidate`; обычное web-открытие не импортирует старые SharedPreferences/localStorage. VM-тесты с временным каталогом используют явно замоканные preferences. Supabase-константы принудительно пусты.
- Одновременные страницы кандидата получают общий Web Lock; открытые старые подключения нужно закрыть добровольно. Синтетическая IndexedDB намеренно повышается до v2, а старая v1 её не открывает. **Обычный откат сломан**; это блокер для настоящей миграции, а не решение для реального дневника.
- Кэш содержит только оболочку, а не независимую резервную копию. У этого исследовательского worker не решена уборка старых синтетических кэшей и не доказаны все браузерные гонки/повреждения.
- Отдельные каталоги перенесены из `supplemental_catalogs/`: 99 местных позиций и 29 молочных; помечены 5 исторических и 20 типовых оценок, неподтверждённые микронутриенты не выдумываются. Источники и актуальность нужно дополнительно проверять.

## Воспроизведение сборки — только для изолированной лаборатории

Тестировавшийся toolchain: Flutter 3.47.8, revision `737ba8f885dc774b53b442759999a312c9461e4e`; Dart 3.13.7. Сборка и SDK не входят в архив исходников. После скачивания зависимостей в отдельную среду:

```sh
cd candidate
flutter pub get --enforce-lockfile
flutter build web --no-pub --release --no-wasm-dry-run --no-web-resources-cdn \
  --pwa-strategy=none -O1 --build-name=3.0.1-synthetic --build-number=3
python3 tools/stamp_synthetic_shell.py build/web
```

Stamp принимает только свежий `candidate/build/web`; при прерывании сборки/маркировки нужна новая чистая сборка. ID и контрольные суммы — не подпись и не доказательство безопасности. Исторические файлы `docs_historical/` и `supabase/` не дают разрешения на deployment или миграцию.

Результаты конкретных попыток и точные ограничения — в [`research/rebuild_github_lab/`](../research/rebuild_github_lab/README.md). Нет доказательства безопасной миграции реальных данных, восстановления всех типов документов, поведения Safari/iOS и Android, реального переполнения хранилища, сбоев питания, Auth или облачной синхронизации.
