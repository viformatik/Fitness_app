# Fitness Smart 2.1 — удобный AI-дневник

Опубликовано: https://fitness-smart-navy.vercel.app

## Что нового
- Черновик показывает итоговые калории, вес и БЖУ **на съеденную порцию**.
- Продукты сгруппированы по приёмам пищи, с отдельными итогами.
- Быстрые кнопки «Всё ×½» / «Всё ×2», изменение веса, состава, приёма пищи и удаление лишних позиций.
- Явная дата записи с календарём. Она фиксируется до запроса и не меняется из-за навигации.
- Весь проверенный набор сохраняется одним документом дня. Стабильные ID защищают повтор этого же сохранения от дублей.
- При неудаче набор остаётся открытым. После начала сохранения редактирование блокируется: повтор работает с теми же ID.
- Последние 5 черновиков можно открыть без AI-запроса, в том числе без сети при сохранённой сессии.
- Недавние черновики разделены по аккаунтам, хранят только названия/порции/оценки еды на устройстве,
  без исходных фото, текстовых запросов, ключей и профиля. Не входят в экспорт дневника и облачную синхронизацию.
  Удаляются кнопкой корзины; полная очистка приложения также удаляет их.
- Понятные сообщения о проблемах сети, настройке сервера, квоте и истечении сессии вместо minified-исключений.
- Карточка дневного баланса: оставшиеся калории и БЖУ, вода, простые локальные подсказки.
- Серверный prompt уточнён для фраз вроде «2 булочки на обед, ещё 1 на ужин»; добавлена проверка приёма пищи.

## Границы
AI остаётся оценкой: вес и состав по фото могут быть неверны. Любой результат требует подтверждения.
Подсказки дневного баланса — локальные правила, а не отдельная нейросеть и не медицинский совет.
Стабильные ID защищают повтор сохранения в одном открытом черновике. Повторное открытие блюда и новое
подтверждение намеренно создаёт новую запись — это функция повторного приёма пищи, не глобальный дедупликатор.
Один набор относится к одному выбранному дню; для нескольких дней сохраните отдельные наборы.

- 62 теста пройдены, в том числе 14 новых проверок AI-черновиков, кэша, дат и пакетного сохранения.
- Тестируются: ошибка записи без частично добавленных продуктов, повтор без дублей, параллельная запись,
  сохранение старого дня при смене выбранной даты, расчёт КБЖУ порции, удаление и изменение массы.
- Flutter analyze: No issues found. Release web build успешен.
- Production HTTP 200; main.dart.js совпадает с собранным файлом по хешу.
- Браузер 390×844: Smart → два приёма пищи → сохранить → перезагрузить → открыть недавний черновик без AI-запроса.
  Ошибка квоты отображается по-русски, текст не пропадает. Без ошибок JavaScript / сетевых сбоев.
- Браузерный AI-тест использовал перехваченные тестовые ответы и фиктивную локальную сессию, **не реальный
  аккаунт/вызов Gemini**. Межустройственная синхронизация и реальное распознавание под аккаунтом владельца
  в этой проверке не тестировались.
- Реальная функция food-ai обновлена до v4. Без токена отвечает 401. Настоящее значение ключа не читалось;
  проверено только наличие секрета с именем GEMINI_API_KEY.

Файлы проверок: checks/v3_*. Более ранние checks/* относятся к предыдущим релизам.
В vercel-static/build.mjs закреплён архив новой сборки (SHA256 проверяется при публикации).
