# Fitness Smart 2.2 — этикетки, уточнение, избранное и отмена

Сайт: https://fitness-smart-navy.vercel.app

## Что нового
1. **Один раз подтвердить 18+ и передачу данных в AI.** Согласие хранится для конкретного аккаунта на этом устройстве.
   Оно не синхронизируется и не входит в экспорт дневника. В Smart есть кнопка «Отозвать согласие на AI».
   После отзыва следующий запрос снова спросит разрешение. При изменении версии политики/провайдера старое согласие не действует.
   После этого обновления подтверждение потребуется один раз: прежняя версия не сохраняла согласие.
   Проверка и подтверждение пищевого черновика остаются — AI может ошибаться в составе и порции.
2. **Режим «Этикетка».** Выберите режим, добавьте чёткое фото таблицы пищевой ценности и укажите съеденную порцию.
   Серверный prompt требует читать видимые КБЖУ, не подставлять типовые значения при неразборчивых цифрах.
   На порцию с известным весом значения переводятся в расчёт на 100 г. Для таблицы на 100 мл без известной плотности
   модель должна вернуть пустой результат, а не приравнивать миллилитры к граммам. Порцию по умолчанию 100 г нужно проверить.
   Это AI-извлечение, не гарантированный OCR и не поиск по штрихкоду; цифры всегда нужно сверить с упаковкой.
3. **«Уточнить словами».** В окне черновика нажмите кнопку, например: «Булочки с творогом, по 90 г».
   Отправляются только открытый черновик и новый текст — без исходного фото, профиля и остального дневника.
   Результат заменяет черновик целиком, а не добавляется поверх него. Если запрос не удался, исходный черновик остаётся.
   Это отдельный AI-запрос с общим лимитом 15/час; платный fallback не добавлен.
4. **Избранные наборы.** Звезда в заголовке черновика → название → закрепить. До 20 наборов, повтор без AI-запроса.
   Набор с одинаковым названием заменяется. Избранное хранится отдельно от последних пяти черновиков,
   только на этом устройстве и для этого аккаунта, без фото. Перед повторным добавлением можно изменить порцию и день.
5. **Отменить последнее AI-добавление.** Кнопка в Smart и действие в уведомлении после сохранения.
   Отмена переживает перезагрузку и работает с исходным днём и ID добавленного набора, не затрагивая другую еду.
   Если одну из записей уже отредактировали, вся автоматическая отмена останавливается, чтобы не удалить правки.
   Избранное и недавние черновики при отмене сохраняются. Это отмена последнего AI-набора, не универсальная история undo.

## Сохранность и проверки
- База не мигрировалась и не очищалась, другие Vercel-проекты не менялись.
- 74 Flutter-теста пройдены (12 новых): согласие/отзыв/новая политика, изоляция аккаунтов,
  границы передачи данных, избранное, лимиты наборов, безопасная и атомарная отмена, даты.
- Flutter analyze — No issues found; Deno check — успешно; release web build — успешно.
- Production HTTP 200; main.dart.js совпадает с локальной сборкой.
- Браузер 390×844: первый запрос → одно согласие → уточнение без нового согласия → избранное → сохранить →
  перезагрузить → отменить → открыть избранное без AI-запроса → фото этикетки без повторного согласия →
  отозвать согласие → отклонить запрос без отправки. Ошибок JavaScript и сетевых сбоев не было.
- Браузерные проверки используют **тестовые ответы AI и фиктивную локальную сессию**. Настоящее распознавание
  этикетки/уточнение через Gemini под аккаунтом владельца и межустройственная синхронизация не тестировались.
- Серверная food-ai v5 активна, проверяет bearer через getUser, неавторизованный запрос получает 401.
- Приватные ключи не читались и не включены в исходники. Временная функция загрузки сборки удалена.

Актуальные подтверждения: checks/v4_*. Старые checks и RELEASE_2.1.md относятся к предыдущим выпускам.
