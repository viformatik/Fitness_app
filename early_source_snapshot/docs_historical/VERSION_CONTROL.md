# Локальный контроль версий

Исходный рабочий проект не имел подключённого удалённого Git-репозитория. Во время аудита был создан локальный baseline `eb7ea3f`, но после пересоздания временного окружения каталог `.git` не сохранился. Исходный commit и его историю восстановить не удалось; исходные файлы и результаты проверок остались в рабочем пространстве. Не считать его доступным для отката.

С этого контрольного состояния начинается новый локальный репозиторий. После каждого проверенного этапа следует создавать новый commit и обновлять `fitness_smart_history.bundle`, чтобы история была переносимой даже при потере каталога `.git`. Bundle содержит код и документацию, но **не** реальные пользовательские дневники, облачную базу, секреты, локальную конфигурацию и не является их резервной копией. Внешний remote/CI не настроены.

Команды для восстановления истории в новой временной среде: `git clone fitness_smart_history.bundle <новый-каталог>`; перед заменой рабочего дерева обязательно сохранить текущие незакоммиченные изменения. Проверять вывод `git status` и совпадение файлов. Не добавлять пользовательские экспорты и секреты; перед коммитом запускать `python3 tools/check_staged_secrets.py` и ручную проверку.
