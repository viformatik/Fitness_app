# Fitness Smart 2.3.1 — исправление молочного каталога

Сайт: https://fitness-smart-navy.vercel.app  
Production: `dpl_FcTpPsE9Mgt1m4D7U628Ekh8XFeq` · https://fitness-smart-j4f8xxhjt-bityi-byte.vercel.app  
Версия: **2.3.1+6**.

## Почему это понадобилось

В 2.3 я ошибся приоритетом: добавил 7 793 записи USDA и онлайн-поиск Open Food Facts, но не закрыл базовый повседневный сценарий — выбрать молоко 0,5%, 1%, 2,5%, 3,2% или местный бренд. USDA — отличная научная база, но она англоязычная и не содержит локальных брендов Приднестровья/Украины/Молдовы. Open Food Facts тоже не гарантирует наличие ТМК, «Благода» или полной линейки «Селянське».

Поэтому добавлен отдельный **оффлайн-справочник из 49 молочных продуктов на русском/украинском**, который работает без интернета и показывается выше англоязычных строк.

## Что добавлено

### Разновидности молока по жирности
Типовые названия на русском: **0%, 0,5%, 1%, 1,5%, 2%, 2,5%, 3%, 3,2%, 3,5%, 3,7%, 4%, 6%**, а также:
- молоко топлёное 1% / 2,5% / 3,2% / 4% / 6%;
- безлактозное 2,5%;
- высокобелковое 0,5%;
- козье 4,2%;
- кефир, ряженка и простокваша в брендовой линейке.

### Бренды
- **Селянське / Селянское / Selyanske** — 0,5%, 1%, 1,5%, 2,5%, 3,2%, безлактозное 2,5%, высокобелковое 0,5%, детское 2,5%.
- **Благода (ТМК)** — 1,5%, 2,5%, 3,2%, 3,5%, топлёное 4% и 6%.
- **Молочная Благодать** — 1,5%, 2,5%, 3,2%, топлёное 4%, кефир/ряженка/простокваша.
- **Домик в деревне**, **Простоквашино**, **Станция молочная**, **36 копеек**, **Молком**, **На здоров’я** — основные молочные позиции.

### Удобный доступ
- В окне добавления еды появилась строка **«Молоко — жирность и местные бренды»** с быстрыми кнопками `0,5%`, `1%`, `1,5%`, `2,5%`, `3,2%`, `3,5%`, `Селянське`, `Благода`, `ТМК`.
- В большой базе добавлены кнопка **«Местное молоко»**, отдельные чипы жирности `0,5% … 6%`, источник **«Региональные молочные продукты»** и сортировка **«По жирности»**.
- Поиск понимает `Селянське`, `Селянское`, `Selyanske`, `Selianske`, `Благода`, `ТМК`, `blagoda`, `tmk`, `молоко`, `milk`, `2,5%`, `fat25`.
- Брендовые продукты можно сохранить в **«Мои продукты»**; у них сохраняются источник, штрихкод и пометка о точности данных.

## Откуда значения

- Для линейки **«Селянське»** использованы опубликованные страницы производителя: 0,5% — 35 ккал / Б 3,0 / Ж 0,5 / У 4,7; 1% — 39,4 / 2,9 / 1,0 / 4,7; 2,5% — 52 / 2,8 / 2,5 / 4,7; 3,2% — 58 ккал. Источники: [0,5%](https://www.loostdorf.com/ru/our-brands/moloko-ultrapasteryzovane-selyanske-05-zhyru-900/), [1%](https://www.loostdorf.com/ru/our-brands/moloko-selyanske-1-5-900/), [2,5%](https://www.loostdorf.com/ru/our-brands/moloko-selyanske-2-5-900/), [3,2%](https://www.loostdorf.com/ru/our-brands/moloko-selyanske-3-2-900/), [безлактозное 2,5%](https://www.loostdorf.com/ru/our-brands/moloko-pitne-bezlaktozne-ultrapasterizovane-25-zhiru-tm-selyanske-950g/). Высокобелковое молоко с 4,5 г белка и 0,5% жира — по [сообщению Союза молочных предприятий Украины](https://uadairy.com/linijka-tm-selyanske-popovnylasya-molokom-iz-vysokym-umistom-bilka/); калорийность для него рассчитана по БЖУ.
- Для **«Молочная Благодать»** использована [опубликованная таблица БЖУ бренда](https://health-diet.ru/base_of_food/food_102273/).
- Для **«Домик в деревне»**, **«Станция молочная»**, **«36 копеек»** и **«Молком»** — страницы Open Food Facts: [Домик в деревне](https://world.openfoodfacts.org/product/4690228109713/), [Станция молочная](https://ru.openfoodfacts.org/product/4607028308796/), [36 копеек](https://world.openfoodfacts.org/product/4600657410960/), [Молком](https://kz.openfoodfacts.org/product/4870007490380/).
- Для **«Благода (ТМК)»** найдено подтверждение существования локального бренда ([ТПП ПМР](https://tiraspol.ru/en/news/molochnaya-i-myasnaya-produktsiya-torgovoy-marki-blagoda/)), но я не нашёл официальной таблицы БЖУ именно по всем жирностям. Поэтому КБЖУ там **явно помечены как ориентировочные по жирности**, с типовыми значениями белка/углеводов из справочников. В карточке продукта написано: «Ориентировочно по жирности; точные белок/углеводы сверьте с упаковкой». Это не выдаётся за точные лабораторные данные.
- Микронутриенты для всех молочных позиций — ориентир по обычному коровьему молоку (кальций, калий, B2, B12 и др.), не значения с конкретной упаковки.

Если прислать фото упаковок ТМК/«Благода», заменю ориентировочные цифры на точные значения с этикетки.
