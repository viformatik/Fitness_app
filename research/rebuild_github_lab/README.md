# Новая реконструкция из GitHub — синтетический WIP, не релиз

Исходная точка — публичный commit `e460050454e6a60a3c21b641006b7258d2c80309`. Новый каталог `candidate/` создан из сохранённых ранних исходников и отдельно восстановленных каталогов. Это **не** потерянный синтетический кандидат и не полное восстановление позднего приложения. Подробные старые отчёты о потерянном кандидате не сохранились и не являются результатами этой реконструкции.

Браузерные harness `browser_probe.cjs` и расширенный `browser_food_probe.cjs` предназначены для одноразовых профилей и loopback-only сетевого namespace, проверяют отпечатки маркированной сборки и используют только `fitness_synthetic_candidate`. Писатель v1 в обоих — **сырой тестовый IndexedDB**, не точная архивная Flutter +14. Его нельзя выдавать за проверку реального клиента. Сам по себе исходник harness не доказывает, что тесты запускались; проверяйте соответствующие сохранённые отчёты.

## Воспроизведение браузерной лаборатории

Сначала выполните изолированную сборку по `candidate/CANDIDATE_SAFETY.md`. Для harness использованы Node 20.20.2, `playwright` 1.56.0 из `package-lock.json` и браузеры, установленные отдельно. В одноразовой среде Linux с `sudo -n`, `unshare`, `setpriv` и `ip`:

```sh
cd research/rebuild_github_lab
npm ci --ignore-scripts --no-audit --no-fund
export NODE_PATH="$PWD/node_modules"
export PLAYWRIGHT_BROWSERS_PATH=/абсолютный/путь/к/отдельному/browser-cache
npx --no-install playwright install chromium firefox  # отдельные скачивания до сетевой изоляции
bash run_isolated.sh chromium /абсолютный/новый/report-chromium.json food
bash run_isolated.sh firefox /абсолютный/новый/report-firefox.json food
```

Аргумент `food` выбирает расширенный сценарий воды, одного продукта и приватных маркеров; без него выполняется прежний сценарий только воды. Дистрибутив может потребовать системные библиотеки для браузеров. Скрипт создаёт loopback-only namespace, сбрасывает привилегии и использует только временные профили; он должен отказать при недостаточной изоляции. Результат создаётся в новом файле, существующий не перезаписывается. Скачанные браузеры и зависимости не являются частью репозитория.

## Ограничения

Ни при каких условиях не открывайте этим прототипом настоящую IndexedDB `fitness_v2`, личные браузерные профили, аккаунты или cloud. Не удаляйте рабочие данные и не развёртывайте эти файлы. Web Lock не защищает старые и посторонние страницы, а повышение версии делает обычный старый откат несовместимым. Реальная миграция, все виды бэкапа, Safari/iOS, Android, несколько устройств, Auth, sync, реальная квота и отключение питания не проверены.
